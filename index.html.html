Deploy to GitHub Pages in 3 Easy Steps

1
Download Your Production File

Click Download index.html in the top-right toolbar. Everything (HTML, Tailwind CSS, icons, and interactive quote JS) is bundled into that single file.

2
Upload to a Public GitHub Repository

Create a new public repository on GitHub named username.github.io, click Add file → Upload files, drag in your index.html, and commit changes.

3
Activate Free Hosting & Custom Domain

Open repository Settings → Pages, select branch main / / (root), and hit Save. Your site goes live at https://username.github.io within 60 seconds!
